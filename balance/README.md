# 밸런스 조정안 v5

[Excel 파일](project2-balance-v5-ko.xlsx)을 함께 첨부했습니다. 2026년 7월 16일 기준의 코드·데이터와 비용 조정안을 정리한 12개 시트입니다.

[경제 사례](../cases/03-economy.md)에서는 114골드로 10골드 상품 네 개를 사면 74골드가 남아 100골드 확장을 선택할 수 없었던 상황을 설명합니다. 시트는 구매와 확장을 함께 선택할 여유를 주는 방향을 검토한 자료입니다.

| 시트 | 내용 |
|---|---|
| 대시보드 | 구매·확장 문제와 경제·전투·가시성의 조정 목표 |
| 현재 기준 | 2026년 7월 16일 코드·데이터의 기준값과 출처 |
| 성장 곡선 | 누적 획득 목표, 상점 진입비, 진입 후 보존 골드 계산 |
| 스폰 타임라인 | 시간대별 적 유지 목표와 근거리·원거리 구성 |
| 적·보스 | 체력, 피해, 보상, 출현 시각 비교 |
| 경제 흐름 | 구간별 성장 목표와 상점 이용 후 남는 골드 |
| 인벤토리 경제 | 확장 비용, 합성 원가, 판매 회수율, 아이템 점유 칸 |
| 패시브 시너지 | 등급별 효과와 발동 조건, 조합별 확인 항목 |
| 무기 DPS | 비교용 계산과 무기별 실제 피해량 측정 양식 |
| 성장·카메라 예산 | 몸집·카메라 변화와 상점 진입·종료 상태 전이 |
| 플레이 모드 입력 | 시간대별 측정값, 구간 판정, 회귀 확인 양식 |
| 데이터 품질 | 코드·계산·실측·설계 목표의 출처와 확인 범위 |

노란 입력 칸은 플레이 측정값을 넣는 곳입니다. 판정에 필요한 지표가 빠지거나 숫자가 아니면 ‘미측정’으로 남습니다. 현재 기록하지 않은 측정값은 비워두었습니다.

실제 공격 범위와 분열을 조정한 내용은 [진화 무기 사례](../cases/05-evolved-weapons.md)에 정리했습니다.
