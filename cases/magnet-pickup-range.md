# 자석 효과의 획득 범위가 잘 느껴지지 않았습니다

플레이 체감 개선 · 2026년 7월 후속 작업

## 발견한 문제

자석 효과를 사용했는데도 아이템을 줍는 범위의 차이가 거의 느껴지지 않았습니다. 문제 상황을 설명하고 코드 분석과 수정에 참여했습니다. 7월 16일 다시 플레이해 아이템을 줍는 범위가 넓어진 것을 확인했습니다.

여기서는 아이템을 줍는 범위의 변화를 확인했습니다. 공격이 너무 넓게 퍼지는 문제는 [진화 무기 조정 사례](evolved-weapon-balance.md)에 따로 정리했습니다.

## 관련 코드

[획득 반경 계산](../code/magnet-pickup-range.cs)은 기본 반경에 로비 업그레이드 비율을 적용하는 현재 구현의 일부입니다. 이 코드는 로비 업그레이드 계산을 참고하기 위한 자료입니다. 자석 패시브의 전체 수정 내용은 포함하지 않았습니다.
